# Jirai Kei · Windose Dark

粉色 Win98 窗口、深紫色地雷系面板，搭配像素字体、蕾丝、爱心和照片角贴。作者：**FuLuTang**。

## 特点

- 统一标题栏、玩家等实体详情窗口、AI 助手、菜单与提示浮层。
- 像素按钮、输入框、开关、日历、标签页与状态指示灯。
- 信封与标题栏图标、空状态小猫、照片绷带和像素爱心装饰。
- 图片、字体全部内嵌，不请求远程资源；固定暗色及主题强调色。
- 主题动效遵循系统减少动态效果偏好及应用的减少特效设置。

## 使用与恢复

使用 VRCX-0 Theme Dev Kit 的本地主题预览功能，选择本主题目录，不要选择整个仓库。替换样式后重新加载预览；停止预览即可恢复原先选定的外观。主题不修改应用代码或账号数据。

已在 Windows/WebView2 的自用 VRCX-0-jirai 构建中检查玩家详情及 AI 助手等界面，并完成合成窗口用例和冻结页面样式回归检查。预览图采用虚构数据的合成布局，不含真实好友信息。
