## 设计要点

| 部位 | 做法 | 来自原作的哪里 |
|---|---|---|
| 整体 | 深紫藏青桌面上摆三扇 Windose 小窗：左 `start`、中 `vrcx-0`、右 `friends` | NSO 桌面多窗口 |
| 窗框 | 1px 靛紫描边加内侧细线；顶部标题条带小方块和三点；底部薄荷细条，左端一小段粉色加小点 | NSO 窗口外框与底部薄荷条 |
| 激活窗口 | 中区标题条用粉色，其余两扇是灰紫 | NSO 活动窗口粉色标题栏 |
| 好友动态表 | 表头底色加 2px 薄荷下边线；点线分隔；悬停行整行填色；类型前加小方块 | NSO 评论列表 |
| 左导航激活项 | 整行填色、左侧粉条、右侧像素爱心 | 像素心来自用户漫画图与 NSO |
| 好友侧栏 | 分组标题前加小方块；自己那一行右上角有极淡的点阵云 | JINE 背景的点阵云 |
| 弹窗 | 粉色标题条、横幅底部一排像素心、深蓝信息区、粉底标签页加薄荷下边线、信息卡片自带小标题条；背后蒙一层紫色 | NSO 三段式系统弹窗 |
| 状态栏 | 做成任务栏：小方块加文字的任务按钮，右侧时钟是凹陷小框 | NSO 任务栏 |
| 桌面底纹 | 像素锯齿，对比度压到约 1.12:1，只留一点质感 | NSO 桌面底纹，夜间几乎被抹平 |

装饰图形（像素心、点阵云、像素锯齿）都来自我们自己画的[原创素材](<original-assets/README.md>)，没有使用参考图像素。

## 浅色原作怎么映射到深色（依据）

[程序取色报告](<palette/palette.md>)从 NSO 浅色、夜间、暗色参考图取样：

![NSO 参考图程序取色色板](<palette/swatches.png>)

1. **强调色保留，中性面压暗加紫**：原作夜间形态（ss-06）里薄荷细条 `#A7EFE3` 变成 `#85F2DD`，反而更饱和；弹窗粉标题 `#EDC9ED` 完全不变；中性灰被染成蓝紫。我们照做：薄荷、粉色保留，底色全部用偏紫的深色。
2. **底纹几乎抹掉**：夜间桌面锯齿纹和底色只差几个色阶。我们的锯齿底纹同样压到 1.12:1。
3. **有意偏离一处**：原作夜间的小方块仍是靛蓝 `#431CC3`，但它的夜间底色只是压暗的浅紫 `#A292DD`，不是真正的深色。放在我们的深紫标题条上，靛蓝几乎看不见，所以按 NSO 暗色骨架“蓝色方块翻成浅粉”的做法，改成 `#ffb8e6`。
4. **可调项**：激活标题条目前用较饱和的 `#d97fc6`。若想更贴近原作，可换成原作的 `#EDC9ED`，深色字在上面对比度更高，但在深色界面里会显得更亮。

## 纯 CSS 可行性核对（已完成，效果图已按结果修改）

子智能体（deepseek-flash）对照真实源码逐项核对了 34 个元素：**能 24、部分 6、不能 4**，详见 [css-feasibility.md](<mockups/windose-dark/css-feasibility.md>)。Lead 抽查了其中两处源码引用（类型筛选 chip 只显示已选项；用户详情弹窗不渲染关闭按钮），属实。第二版效果图做了这些修改：

| 第一版 | 问题 | 第二版 |
|---|---|---|
| 好友动态工具条右侧有表格／列／刷新／更多 4 个图标 | 表格模式下这些按钮不存在 | 改成真实的“表格／分栏”切换、“类型”下拉、搜索框内嵌日期范围 |
| 7 个类型 chips 常显 | 真实只显示已选中的筛选，默认一个都没有 | 删掉，表示默认状态 |
| 好友动态表、好友侧栏有“选中行” | 两处都没有持久选中态 | 改成悬停态 |
| 类型前 6 种颜色的小方块 | 真实只能区分位置变动、上线、下线三类 | 其余三类统一用浅粉小方块 |
| 状态栏 VRChat／SteamVR 画成任务按钮 | CSS 区分不了这几段 | 所有状态段统一一种胶囊样式 |
| 弹窗标题条带关闭按钮，横幅是固定渐变 | 详情弹窗没有关闭按钮，横幅是用户自己的图片 | 标题条只做装饰（`user` 加三点），横幅画成匿名占位；弹窗宽度按真实的最大 72rem |
| 信息卡片顺序不对、缺一张 | 和真实顺序不符 | 按真实顺序排，补上“好友关系记录” |

**实现时要注意的**（来自核对报告）：
- 中区的标题条要挂在 `.vrcx-0-page-scaffold` 上，不能用 `.vrcx-0-main-content` 的伪元素，那两个已被壁纸层和拖拽高亮占用。
- 左导航激活项的像素爱心可能和快捷键、计数徽章重叠，只在没有徽章的项上显示，或往左让位。
- 窗口标签 `start`／`vrcx-0`／`friends` 是 CSS 生成的固定英文，不随界面语言切换。
- 桌面锯齿底纹需要把相关表面设成透明才看得见；用户开启官方壁纸时会被壁纸盖住。
- 还有 4 项没在真实应用里验证（例如弹窗最终是否可滚动），实现后在 DevKit 里确认。

### 能不能改：结论

依据三份调研（deepseek-flash 子智能体，均附源码行号）：[主题硬限制](<research/theme-limits.md>)、[头像与图标 DOM](<research/avatar-icon-dom.md>)、[像素字体](<research/pixel-fonts.md>)。

| 想改的 | 结论 | 说明 |
|---|---|---|
| 头像框 | **能** | `clip-path` 切成像素八角，要先清掉圆角；外框画在不裁切的外层容器上；状态点改成像素方块。例外：好友列表页的 24px 头像是裸 `<img>`，挂不了装饰，只能改形状 |
| 像素字体 | **能** | CSP 不限制字体。拉丁用 Silkscreen（OFL），ASCII 子集内联约 2.2 KB；中文可用 Fusion Pixel 12px（OFL），按 VRCX 实际界面的 943 个汉字子集化后内联约 53 KB。要通过 `--vrcx-app-font-family` 加 `!important` 覆盖。**限制**：点阵字只在 12px 及其整数倍清晰，13px 会糊；Windows 125%／150% 缩放也会让它不够锐利；用户昵称里的生僻字会回退普通字体 |
| 背景小元素 | **能** | 全部用原创素材的 data URI，现在共约 16.5 KB |
| 动态效果 | **能** | `@keyframes` 没有任何限制。应用的“减少特效”开关会强制停掉所有主题动画，主题反制不了，这正好是对的；因此动画只能当点缀，不能承载信息 |
| 图标 | **大部分能** | lucide 图标的 `<svg>` 带稳定类名（如 `lucide-bell`），可以隐藏原线条、用 mask 画上像素图标。要注意别名（“游戏日志”的类名是 `lucide-rotate-ccw-clock`）；主题切换按钮、世界房间封面不是 lucide，换不了。建议只换几个最显眼的，不全量替换 |
| 文件大小 | **够用** | 安装时硬上限 1 MiB；仓库不检查 CSS 内容。目前估算：样式约 30 KB + 素材 16.5 KB + 拉丁字体 2.2 KB + 中文像素字体 53 KB，约 100 KB |

**做不到的**：改 DOM 结构（例如把导航改成图标网格）、加新按钮或新功能、读取用户数据做逻辑判断。另外，主题的安装来源是官方社区主题仓库 `Map1en/VRCX-0-Community-Themes`，发布时要提 PR 到那里。

### 效果图里新加了什么

- **头像**：所有头像改成像素八角加描边，自己的头像描粉边；状态点变成像素方块，颜色不变。
- **像素字体**：窗口标签、时间戳、时钟、计数用 Silkscreen；中文暂时仍是普通字体，像素中文字体等你决定要不要。
- **图标**：铃铛、星星、搜索、定位、好友动态、设置换成我们画的 12×12 像素图标，其余保留原线条图标。
- **背景**：桌面薄荷圆点，加两层像素星空错开闪烁；每个窗口内铺一层极淡星空（对比度 1.20:1，不影响阅读）；左栏和右栏空白处放点阵云；好友动态表下方空白处放心、结、十字、兔子的极淡底纹。
- **动效**：激活窗口标题条上的方块像光标一样闪；左导航当前项的像素爱心有心跳；状态栏“正在加载”下方跑彩虹像素条。系统或应用开了减少动效时全部停止。

新增的原创素材是像素星星、像素星空平铺图和 6 个像素图标，见[素材对照图](<original-assets/screenshots/assets-4x-sheet.png>)。
