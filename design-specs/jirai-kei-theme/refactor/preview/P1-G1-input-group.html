G1 · Input Group

当前 artifact 的外框已统一为 #201936 / 1px solid #6c5ce0。下面展示外框同一、内容组合有别的原则；第 6 格只用于对照 inventory 旧态。

01 · 默认字段组

Standalone / default
共享直角外框与 inset 阴影；control 透明嵌入。

02 · 聚焦状态

Focus within
名称
粉色 focus outline 是独立状态，不是另一种静态边框皮肤。

03 · 工具栏组合

Toolbar · addon + control + button
状态
Addon 保留文字色，按钮保留粉色 bevel 与交互焦点。

04 · 搜索 / Chips

Search · chip + control + action
⌕好友 ×
Chip 及输入本体透明嵌入组框；不叠加第二层边框。

05 · 数字步进器构成

Numeric · addon + control + step buttons
数量
外框仍共用；窄步进按钮属于子组件，不并入通用 control 皮肤。

06 · Inventory 历史 fingerprint 非当前外观

Legacy bevel reference
#2a2147 · 四边斜面 #69557c / #fdf4ff
用于识别 inventory 的 37-observation 旧样本；当前 CSS 不再给 input-group 使用此边框。
