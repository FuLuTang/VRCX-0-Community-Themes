客观利弊对照

方案优点缺点 / 代价
A · 只给字段本体纯 CSS，可覆盖裸字段且不改现有 DOM；规则直接，适用于统一字段本身外观。焦点环落在 input 本体，形状和搜索组的外壳 ring 不同；没有独立图标 addon 槽。
B · 连外壳一起给聚焦环可围住完整组，带图标槽，更接近搜索框的呈现；外框与输入内容职责分离。必须调整 HTML，把裸 input 包一层结构；需留意不同字段组件与布局如何适配外壳。

B 更接近搜索框的样子，但需要改 HTML 结构；A 纯 CSS，但聚焦环形状会简单一些。此页所有字段统一固定 38px 高度仅为展示用，不是主题值；横向宽度、栏间距、图标字符也都是展示用。
