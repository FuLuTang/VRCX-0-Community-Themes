⚠️ 副作用 / 边界警示

  • input-group-control 双重描边风险：当前是透明、无阴影的内层 control；若 B3 selector 同时命中它，外层 group 与内层会各画一圈。其自身 border 未显式重置为 0（规则只有透明背景、无 shadow），因此不能假定在所有浏览器都绝无边线。
  • input-group 外框外观变化：当前 group 是 1px #6c5ce0 / #201936；改为 B3 将改变边宽、背景与 bevel。addon 本身无边框，边框由 group 拥有；组内按钮另有独立皮肤。
  • file：现有规则只定制 ::file-selector-button。把通用 B3 施加到 file input 本体可能改变原生文件名区域与选择按钮布局/appearance。
  • color：swatch wrapper / swatch 是原生子部件。统一本体背景和 padding 可能挤压/改变色板面积；swatch 自有边框不能误作文本框边框。
  • number：步进器由 UA 控制且未见主题规则；改写 appearance/尺寸可能影响 spinbutton 操作与可见按钮。
  • login：局部规则独立设 2px radius、#8c71b0 边、#16112a 底与 recessed shadow；login focus 变直角。无上下文 B3 selector 可能覆盖这组明确差异。
  • 不属于文本框家族：checkbox、radio、range 有各自的自绘外观/轨道滑块规则；不能按 input 标签整体套 B3。hidden/代理 input 也不应恢复成可见框。
  • 原生搜索/日期字段：基线未提供完整外观契约；贸然加入 B3 会从 UA 外观切换为自绘框，且可能改变浏览器内置图标/操作区。
