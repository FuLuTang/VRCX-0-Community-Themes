原生 <input>：当前 vs 建议收敛

主题并未给所有裸 input 一个通用字段框。普通 text/number/search 在左侧保留 UA 外观；右侧演示显式补齐文本字段皮肤，同时保留 file、color、range、time 的类型专属部件。

原生 input ≠ [data-slot="input"]CSS 内嵌，可离线查看双击本文件打开

text

普通文本输入；inventory 没有通用裸 input 框规则

当前主题

UA 默认外观 + 字体继承

建议收敛

共享暗底、紫边、内阴影

number

数值字段；保留原生 stepper 交互

当前主题

没有被字段 selector 覆盖

建议收敛

皮肤统一，不改原生步进器

search

若位于 input-group，边框应由外层容器绘制

当前主题

独立裸 search 未获 slot 皮肤

建议收敛

组内 input 则需排除独立边框

file

只定制 ::file-selector-button，不把整行改成文本框

当前主题

保留浏览器文件选择行为

建议收敛

按钮皮肤保留，文件名区原生

color

swatch 有专门边框；应保留颜色选择器语义

当前主题

专属 swatch 样式

建议收敛

不套文本字段的 padding/阴影

range

独立轨道/滑块规则；entity dialog 有专门 hit-area 分支

当前主题

专属 track/thumb + focus

建议收敛

保留范围输入的触控面积

time

共用字段规则并保留主题时钟图标

当前主题

fields-toolbar 有纳入字段底框

建议收敛

字段基线 + 保留 picker indicator
说明：当前列依据 theme.css 现有规则构造，并非某特定操作系统的像素截图；浏览器 UA 对原生控件的绘制会因平台而异。inventory 的 native:input 记录没有逐项 type，因此这里展示的是类型规则归类，不对 fingerprint 做超出数据的硬映射。
