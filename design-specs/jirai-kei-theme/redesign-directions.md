# 地雷系主题重新设计：旧方向稿（保留历史）

> **2026-10-11 更新：艺术主参考已更换。请先看[带图的艺术主参考与新版三方向](<art-style-review.md>)：①Windose 紫系像素桌面、②粉黑系带蕾丝、③小恶魔暗夜。** 旧稿过度依赖编辑器主题，下面的色板／推荐不再作为当前结论；保留仅供回溯，不要求用户从旧 A/B/C 中选择。

状态：旧方向提案，未实现。未修改正式主题。

## 1. 本轮的改变

不把当前 Noir Ribbon 的色板、纯 SVG 装饰、极低装饰密度当成需求。新的目标是：在 VRCX 的真实三栏内容中呈现明确的地雷系／病みかわ身份，而不是做一份偏粉的程序员主题。

依据：[逐图评审](image-review.md)。已逐张审阅 21 张软件／终端图、3 张直播图、5 张素材参考，以及既有登录和三栏骨架。直播图负责装饰语言，软件图负责阅读／交互层级；终端色样不作为 UI 母版。

## 2. 内容优先级与共同假设

- 左栏：导航与账户入口；中间：好友／活动／世界的数据；右栏：头像、用户或世界详情；上下：窗口动作和服务状态。
- 此次仍是社区 CSS 主题，不重做业务功能，不增加直播倒计时、社交标签、虚构统计或广告。
- 用户名、世界名、状态、更新时间优先于装饰。表格行可用选择色、细分隔、轻微材质，但不在文字底下铺高对比爱心。
- 头像和世界图片保留原色，不强行染粉；在线、忙碌、离线、警告、危险动作保留明确语义。
- 可改变面板、外框、主辅色、控件材质，不能隐藏窗口关闭／退出／登录／恢复入口。
- 阅读字体继承应用 CJK 回退栈；标题和正文不使用全局花体。宣传图可以单独设计品牌字。
- 主程序仓库只读，当前其他会话 merge 不能作为本轮测试环境。既有截图仅作为记录，不宣称重新运行应用。
- [标题栏](</home/fulutang/Documents/Github/VRCX-0-jirai/src/components/layout/AppTitleBar.tsx#L88-L169>) 默认 h-8，右侧动作多，不能照直播图塞大型蝴蝶结。
- [弹窗](</home/fulutang/Documents/Github/VRCX-0-jirai/src/ui/shadcn/dialog.tsx#L68-L97>) 默认 p-4 且可滚动，装饰必须在可证实的安全空间里，不假设大留白。

### A · 灰粉缎带（优先推荐）

**目标不是微粉暗色，而是“灰粉外壳＋炭灰内页”的完整衣装感。**

参考图：借鉴灰粉菱格、黑色波浪缝边，以及深灰实底阅读区。**这是参考作品，不是我们的设计成品。**

![A 方向参考：IPPU 灰粉菱格与波浪缝边](</home/fulutang/Documents/Github/VRCX-0-Themes-JiraiKeiKuteWin98/design-specs/jirai-kei-theme/references-gpt/ippu-yamikawa-overlay.jpg>)

补充参考：浅粉窗口包边与深灰内容区的分工。

![A 方向结构参考：Pink Panda](</home/fulutang/Documents/Github/VRCX-0-Themes-VSCode/design-specs/jirai-kei-theme/references/vscode-pinkpanda-sample-1.png>)

- 标题栏／状态栏：灰粉结构条，深色文字和真实图标；不用大面积发光，不添加假的交通灯。
- 左导航：灰莓实底，激活项是一片明确的玫粉缎带；细缝线靠边，文字居中不被图案穿过。
- 中间好友表格：炭灰实底，表头比行底稍亮，选中整行灰莓；状态颜色不改。搜索控件沿用布局。
- 右详情：顶部封面区域可见菱格，不给整块文字正文铺纹；头像外圈像窄缎带边，不改头像本身。
- 卡片／弹窗：灰粉标题或下缘波浪缝边，主体炭灰；单个结只能落在实际有留白的位置。小尺寸下宁可去掉结而保留边条。
- 主要层级靠外壳／内页／激活项三层，不重复堆多圈细框。
- 候选材料：处理后的 diamond 透明纹样、heart 透明纹样。square lattice 实际有内方框与对角线，不是普通格子，用量需比 diamond 更少。

### B · 奶粉黑蕾丝

**这条明确离开当前全暗色方向：浅色的内容、深色的框架。**

参考图：借鉴大面积浅粉、爱心底纹、深色蝴蝶结与独立白色阅读框。**这是参考作品，不是我们的设计成品；黑缎侧栏与原创花边是待实现的提案。**

![B 方向参考：サクラミ 浅粉爱心与深色蝴蝶结](</home/fulutang/Documents/Github/VRCX-0-Themes-JiraiKeiKuteWin98/design-specs/jirai-kei-theme/references-gpt/sakuramii-jirai-overlay.jpg>)

补充参考：浅色三栏内容与表格的阅读层级，只取布局，不取绿色配色。

![B 方向结构参考：Maple 浅色三栏](</home/fulutang/Documents/Github/VRCX-0-Themes-VSCode/design-specs/jirai-kei-theme/references/obsidian-maple-main.webp>)

- 标题栏：黑缎底＋粉白文字；状态栏可奶粉底＋深字，避免整屏所有表面都浅粉。
- 左导航：黑底，粉白字，激活项深玫红；黑色与浅主区形成明确空间分工。
- 中间内容：粉白实底，正文深灰莓，搜索框／表头是奶粉；好友行保留轻分隔，不铺任何实心图案。
- 右详情：奶粉封面＋稀疏爱心，正文粉白实底；原头像原色，框边用黑色细线。
- 弹窗：黑色或深灰莓标题区＋浅色正文，像小型装饰窗；footer 按真实组件布局，不新增虚假的标题栏功能。
- 蕾丝做法：不使用当前历史扫描；选择后再原创绘制一个干净、可辨认的波浪缝边，构造不同于商品图。
- 验证重点：darkMode:false 下 sidebar/popover 混合色的继承与硬编码类；不宣称目前已兼容所有页面。

### C · 糖毒复古窗

**把病みかわ的识别点放在窗口形态，而不是哥特服饰材质。**

参考图：借鉴黑格纹外壳、粉色复古小窗和斜纹标签；角色与滴落轮廓不复制。**这是参考作品，不是我们的设计成品。**

![C 方向参考：MellCat 融化病みかわ与复古聊天窗](</home/fulutang/Documents/Github/VRCX-0-Themes-JiraiKeiKuteWin98/design-specs/jirai-kei-theme/references-gpt/mellcat-melting-overlay.jpg>)

补充参考：莓粉激活导航、粉色细框和暗色内页的强弱关系。

![C 方向交互参考：Kawaii Dark](</home/fulutang/Documents/Github/VRCX-0-Themes-VSCode/design-specs/jirai-kei-theme/references/vscode-kawaii-theme-market-preview.png>)

- 外壳：近黑＋轻细格，格纹出现于安全空隙／封面，不进入数据阅读面。
- 标题栏／弹窗标题区：更明亮的粉色实条与深字，窄双线边；窗口关闭按钮保留真实位置与危险 hover。
- 左导航：粉色激活矩形与小面积斜纹；不把所有图标换成药丸／绷带。
- 中央：墨黑实底数据页，用莓粉选中态；按钮像小型复古扁窗标签，仍保留正常 focus。
- 右侧：头像详情封面可有一个原创软边／小心形印记；不复制 MellCat 的滴落轮廓、不引入角色资产。
- 弹窗：粉标题＋实底正文，有点“旧聊天室窗口”的语气；只有主题视觉，没有额外业务功能。
- 无持续闪烁／心跳／粒子；如将来加动效也仅限状态切换并支持 reduced-motion。
- 棋盘格只用于非常窄的边条或宣传图，不能覆盖整块主窗体；Kenney square lattice 不等于普通直格，简单网格可用原创 CSS。

## 5. 交互、内容状态与响应式约束

- hover：边色／底色变化，不能隐藏文字或令所有状态发亮；选中不只靠装饰图案。
- focus：独立于纹样的可见焦点边；outline 不能被圆角容器或装饰层裁掉。
- disabled：保留原生 disabled 逻辑，不把禁用主按钮画得像可点击；评估实际文字，不套纯色验算。
- 错误：输入、toast、危险动作仍有明确错误色与文字；三条候选都不把红色状态强制换成装饰粉。
- loading／empty：沿用真实空状态／spinner／骨架，不能新增假在线人数；空白区域可用极淡纹样，但提示文字仍在实底上。
- 窄侧栏／小窗口：不靠固定宽度的装饰跨越三个面板，纹样周期随局部面板测试；长中文和世界名保留截断／换行策略。
- 动效：本轮静态素材，不做 GIF。后续转场不超过组件需要，尊重 prefers-reduced-motion 和应用 reduce-effects。

## 7. 预览呈现与下一步

1. 先由用户选择 A／B／C 或明确混合关系，再实现高保真三栏原型和主题实验；本轮不抢先覆盖正式 CSS。
2. 原型使用同一批匿名演示数据，标明 demo；同尺寸、同位置比较好友表格、详情、弹窗和登录，不暗示实机验证。
3. 预览主图用完整三栏窗体，保证缩到商店尺寸仍能看到结构和身份。主题名放窗外，不复用工程注释画面。
4. 拍实机／生成预览前先检查隐私；若静态合成则明确标注，不冒充真实用户截图。
5. 最终对比度、键盘状态、关闭／恢复、缩放、小窗口、纹样滚动关系必须在可用测试环境再验证。

推荐先选 A：它能让黑粉服饰语言落在我们已有三栏上，又不是旧版几乎看不出的细线。B 是更大胆的浅色反差；C 是更鲜明的亚文化复古桌面。这个推荐是设计判断，不是对用户喜好的预设。
